# 미반영 항목 대장 (Unmodeled / Partially Modeled)

이 문서는 **모델에 없거나 반쪽만 들어간 메커니즘**을 한곳에 모은다. 목적은 두 가지다.

1. 시뮬 결과를 읽을 때 "이 숫자에 무엇이 빠져 있는지"를 즉시 확인할 수 있게 한다.
2. 나중에 채워 넣을 때 무엇이 필요한지(수치 출처·구현 위치)를 잃어버리지 않는다.

작성 2026-08-11. 항목을 채우거나 새 미반영을 발견하면 여기서 같이 갱신할 것.
`[H-*]` 태그는 코드 주석의 가설 태그와 대응한다.

**여기에 적지 않는 것**: 게임 규칙대로 이미 맞게 구현된 것(관통 배타 등),
모델의 목적상 의도적으로 범위 밖인 것(단일 대상 더미의 라인전·버스트·사거리 등),
사용자가 확정한 모델 가정(루난 Q 확산 반환 계수 등 — 아래 루난 행 참조).

## 4. 엔진·모델 규칙

| 항목 | 내용 |
|---|---|
| **처치 시각 양자화** | 스킬 이벤트 경계에 킬이 걸리면 공속 증가가 DPS 로 환산되지 않는다. 코어 타이밍별 ±2% 노이즈 — 소수점 비교 금지. 미세 효과(예: 루난 계수 변화)를 잴 땐 더미 체력을 키워 킬타임을 늘릴 것 |
| 경계 관통 합성 | `Terminus.on_hit` 이 `armor_pen_percent += 0.10`(3스택 = 30% 가산) → 다른 %관통과 겹치면 곱연산 규칙 위반. **관통 배타 규칙 때문에 현재는 도달 불가 경로**라 수치 영향 0. 배타 규칙이 풀리면 즉시 버그가 된다 |

## 5. 피흡(지속력) — 현재 구현 상태

**이미 이벤트 기반으로 계산되고 있다** (`engine._build_sustain_metrics`). 매 피해 이벤트에서
실제 입힌(경감 후) 피해를 두 채널로 나눠 누적한다.

- **생명력 흡수(lifesteal)** 대상 = 평타 본체 물리·마법 + 평타 고정피해 + **몰왕검 온힛**.
  크라켄·구인수·경계 등 다른 온힛 마법과 스킬 피해는 제외(실 LoL 규칙과 일치).
- **모든 피해 흡혈(omnivamp)** 대상 = **스킬 포함 총 피해**(`total_damage_dealt`).
- 회복량 = `흡혈대상딜 × LS율 + 총딜 × OV율`. 흡혈률은 아이템 `stats` + `champion.rune_lifesteal`(핏빛길).

실측 예 — 베인 4코어, 도란활+탐식(옴니뱀 4%)+핏빛길:

| 빌드 | LS율 | OV율 | 흡혈대상딜 / 총딜 | 회복 |
|---|---|---|---|---|
| BotRK-구인수-경계-PD | 10.0% | 5.5% | 3616 / 6049 | 362 + 333 = **694** (113/s) |
| 피바라기-구인수-경계-PD | 15.0% | 5.5% | 3435 / 5808 | 515 + 319 = **835** (127/s) |

> ⚠️ 위 실측 예는 **선형 성장 근사 시절(2026-08-11 이전)** 수치다. 성장 곡선 정정 후 재측정 필요.

## 우선순위 제안

1. **발동률 계수** — 수호천사·철갑궁·피바라기·멜모셔스의 "교전 기준 상한선"을 실전 기대값으로
   낮추는 계수. 쿨다운(300/90초)과 문턱 조건은 이미 상수로 보존돼 있어 계수만 정하면 된다
2. **회복 상한** — 만피 초과분 버림·치유 감소 미반영
3. **데이터 누락 감사** — 수호천사 방어력 45, 시미터 마저 35·흡혈 10% 가 연달아 누락돼 있었다.
   전 아이템의 방어·지속력 스탯을 원본과 한 번 대조할 필요
