# Cog'Maw 순차 최적 빌드 탐색 (미래 할인 DP) — 설계

날짜: 2026-07-06 · 상태: 사용자 승인됨 · 선행: Task 7(C44 W-전용 버그 모델) 완료 후 구현

## 배경 / 요구사항 (사용자 제안)

기존 랭킹은 완성된 4코어 경로 전체를 가중합(4:4:3:3)으로 일괄 평가한다. 사용자 제안:
**매 코어 시점의 의사결정 모델** — "0코어일 때는 1~5코어 시점 파워를 미래 할인율을 고려해
계산해 최적을 고르고, 1코어일 때는 2코어부터, … 이런 식으로" 다음 아이템을 선택한다.

사용자 확정 파라미터:
- **할인율 γ = 0.9** (j코어 시점에서 k코어 파워의 가치 = γ^(k−j) × Power_k)
- **파워 지표 = DPS와 DPG 둘 다** — 각각 별도 최적화, 두 궤적 모두 출력
- **범위 = 코그모 파일럿**, 호라이즌 5코어(티어5 모델 기정의: lvl17, HP3000/방150/마저90)
- 기존 가중 랭킹은 유지(병행 출력) — 대체 아님

## 모델

- 상태 = 보유 아이템 집합 S (|S| = j ∈ 0..5). 순서는 상태에 안 들어감(파워는 집합에만 의존).
- 가치함수(지표 m ∈ {DPS, DPG} 별로):
  `W_m(S) = 0` (|S|=5) ; `W_m(S) = max_x [ γ·Power_m(S∪{x}) + γ·W_m(S∪{x}) ]`
  여기서 x는 슬롯 |S|+1 후보 중 S와 중복·방관 배타 위반이 없는 아이템.
- 최적 다음 아이템 = argmax. 전수 시뮬 기반 결정론 모델이라 기댓값=값이며, 최적성 원리에
  의해 "매 시점 재계산"과 "최적 연속 경로 추종"은 동일한 궤적을 준다.
- Power_m(S) = 티어 |S| 시점의 시뮬 결과 (`simulate_cogmaw_core_path(S, |S|, …)`;
  DPG = DPS / (총골드/1000)).

## 구현

- **신규 모듈 `adc_sim/simulations/cogmaw_sequential.py`** (기존 cogmaw.py 불변, import 재사용).
- 후보: 슬롯 1~4 = `COGMAW_CORE_CANDIDATES[tier]`, **슬롯 5 = 1~4티어 합집합(20종)**
  (티어5 전용 후보 리스트 부재 — 설정 상수로 두어 추후 조정 가능). 방관 배타
  `{terminus, ldr, mortal} ≤ 1` 동일 적용.
- 평가 조합: 룬 {치명적 속도, 집중공격} × 패키지 {A(Bld+Zerk), B(Bow+Glut)} × 지표 {DPS, DPG}
  = **궤적 8개**. 패키지는 궤적당 고정(시작 시 선택되는 현실 반영), 궤적 간 비교로 우세 표시.
- 캐시: `(frozenset(S), tier, pkg, keystone)` → (dps, gold) 메모이즈. 상태 수 ≈ Σ C(20,j)
  (j=1..5, 배타 필터 후) ≈ 1.9만 집합 → 시뮬 ≈ 7~8만 회, 수 분~10분대. `__main__` 전용
  실행(기본 cogmaw 랭킹에 미포함), 표만 출력(헤드리스 안전, plt 미사용).

## 출력

궤적(룬×패키지×지표)마다:
1. 구매 순서 0→5코어: 각 스텝의 선택 아이템, 해당 코어 DPS·DPG·누적골드, 할인합 W.
2. **각 분기점의 대안 top 3** (선택지별 `γ·Power+γ·W` 값) — "왜 이 템이냐"의 근거.
3. 비교행: [CTRL]·[CTRL2]를 같은 할인합 척도로 평가한 값. (기존 가중 랭킹 top1 비교행은
   런타임 비용 때문에 `--with-top1` 옵션으로 완화 — 파일럿에서는 플래그 파싱만, 미구현.)

## 테스트

- DP 최적성: 소형 합성 풀(아이템 3~4개, 수계산 가능한 가짜 Power 주입)에서 W값·궤적이
  수계산과 일치. Power 주입은 시뮬 함수 파라미터화(또는 monkeypatch)로.
- 궤적 합법성: 슬롯별 후보 제약·중복 없음·방관 배타 ≤1.
- 캐시 정합: 동일 (집합,티어,패키지,룬) 재호출 시 시뮬 미재실행(호출 카운터).
- 헤드리스 스모크: 축소 풀로 end-to-end 1회(전체 풀 실행은 수동 검증).

## 한계 (명시)

- "그 시점 파워"만 본다 — 골드 수급 속도(싼 템이 코어 도달을 앞당기는 효과)는 γ에 뭉뚱그려짐.
  골드→시간 변환 정밀화는 스코프 밖(후속 후보).
- γ=0.9 는 가정값 — 민감도 스윕(0.7/0.8/0.9)은 후속.
- 티어별 타깃 스탯/레벨은 기존 `CORE_TARGET_STATS`/`CORE_COGMAW_LEVELS` 그대로.
